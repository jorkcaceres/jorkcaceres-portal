# Portal Jorkcáceres

Portal privado para clientes y administración de Jorkcáceres, con encuestas públicas de satisfacción.

## Primera versión visual

Esta primera entrega contiene una interfaz navegable con datos de demostración para validar la experiencia:

- acceso e inicio del portal;
- proyectos, información, pagos y encuestas del cliente;
- encuesta pública CSAT;
- acceso inicial al área administrativa.

La siguiente etapa conectará autenticación, datos, almacenamiento de comprobantes y reglas de acceso mediante Supabase.

## Publicación

Hostinger publica el contenido de este repositorio en `public_html/portal`, asociado a `portal.jorkcaceres.com`.
